Design System · Overview

Agentic Design System

A design system built to be read the same way by a designer, a developer and a model generating from it - every token, component and rule documented once and reused everywhere. Start with Foundations for the raw tokens, Components for the 58-plus building blocks, or jump straight to a Pattern or Template already assembled from them.

Start here

The four sections everything else in this system builds on.

Foundations

Color, spacing, radius, borders, shadows, typography and icons - the raw tokens every component is built from.
Components

Every button, form control, overlay and data-display element - each with live states, sizes and a Machine View JSON spec.
Patterns

Recurring problems - empty states, confirmations, multi-step flows - solved once so they're solved the same way everywhere.
Templates

Full page layouts assembled from patterns and components - a starting point instead of a blank canvas.

Guidelines & governance

How and why the system makes the decisions it does - read these before proposing an exception.
