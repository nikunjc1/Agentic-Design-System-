Connect to Figma

  1. Start the local bridge from this project: node tools/component-bridge.cjs.
  2. Open this page through the bridge, then open Agentic Contract Bridge in your Figma document and connect.
  3. Choose your components and select Export to Figma. Keep the plugin open until the export finishes.

What’s included

Saved foundation tokens and the selected editable components. Standard Button appearances are grouped into one family; the icon button is exported separately.

Large selections can take several minutes. Progress, warnings and any failed components appear here. Some browser layouts require approximation in Figma; review the result in your document.

Use with your AI tool

  1. Review your project setup and customize the foundations you need.
  2. Review the component guidelines, choose components from the sidebar, and customize and copy their prompts from the detail pages.
  3. Select the relevant documentation here and download the Markdown file.
  4. Attach the file and component prompts to your AI tool. Ask it to use the saved tokens and verify the documented component behavior, responsiveness and accessibility.

The AI tool runs outside this workspace. Review and test its output before using it.

The export is a snapshot. Regenerate it after changing your setup or foundations.

HTML and CSS examples target the web. Native mobile and desktop products need platform-specific implementations.
