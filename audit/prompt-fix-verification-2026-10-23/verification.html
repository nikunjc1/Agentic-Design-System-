Implementation

  • A shared export path captures effective text, numeric and boolean properties. Hidden conditional fields are excluded; dimension inputs retain canonical values.
  • Per-combination Size/Radius/Content instructions remain scoped to their copied combination.
  • Referenced CSS aliases are exported with their full dependency chain.
  • Focus and shadow instructions use the same semantic tokens as their previews.
  • State inventories follow the preview state arrays; Loading content matches the rendered labels and spinners.

The separately reported default-selection questions remain the existing intentional workflow. Application appearance was preserved, along with the working-tree edits present before this fix.
