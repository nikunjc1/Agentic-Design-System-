    One active project per browser, not a list: there's no separate create, switch or duplicate here - saving this form always edits and replaces that same one profile, it never creates an isolated second one alongside it. Foundation values (Colors, Spacing, Typography, etc.) are owned by this workspace as a whole, not by any one project - they're shared and unaffected by what you save here, in either direction.

    Implementation contract

    Saved validated choices override project recommendations, which override system defaults. This implementation contract governs static specimens. Resolved tokens in the current export are authoritative values. Component exceptions must name the affected role and reason.

    User and task flow

    Choose a product and delivery platforms, choose a role, review, save, then configure Foundations and export. Resume or discard an existing draft explicitly. This workspace holds one editable project profile with shared Foundation settings, rather than isolated projects.

    Navigation and recovery

    Step links and reload advance only after earlier required fields validate. Back preserves entries. Final submit checks both earlier steps and focuses the first error. Invalid or future drafts have backup/discard actions. Failed discard keeps the draft notice. Successful save moves focus to confirmation; Back returns to editable steps.

    Context and readiness

    One delivery platform can supply a platform recommendation; multiple platforms use product context. Explicit editor choices win. Readiness distinguishes a valid saved record, a resolved default and recovery needed. Neither saved nor default means verified. AI is documented as examples, with no live execution.

    Categories and identity

    Dashboard describes a data-focused product; Desktop web describes delivery. Choose AI Product for an AI-led experience, and Other only when no category fits. Name, email and designation are optional and excluded from handoff unless opted in. Returning from docs preserves the durable profile and chosen overrides.

    Handoff

    Export all nine Foundations, effective values in both themes, rules, font dependencies, icon-reference assets and unresolved acceptance checks. Do not claim a published release or send an invitation from a local example.
