Restore

Restore creates a new version. It never overwrites - nothing is deleted, and the impact is previewed before confirming.

Restore version 3.1.0?

This creates a new version from the 3.1.0 configuration. Nothing is deleted - 3.2.0 remains in your history. Current 3.2.0 → New version 3.3.0.

  • Restore is Owner / DS-Admin only.

  • The new version starts as draft and follows the normal publish path.

Component Guide

Accessibility

  • Proper <th scope="col">, sort state announced, row actions keyboard-reachable (SC 1.3.1, 4.1.2).
  • Compare diffs are not color-only - +/~/− and text carry the meaning (SC 1.4.1).
  • Row action menus meet a 24×24px target with adequate spacing (SC 2.5.8).
  • A sticky table header must not obscure a focused row (SC 2.4.11 Focus Not Obscured).

Related
