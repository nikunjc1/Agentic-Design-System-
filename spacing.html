Recommended global model

The strongest systems don't force a single unit - they combine three, each doing a different job.

Micro spacing Icon-to-text, badge internals, compact controls, fine alignment 2, 4, 6, 8px
Component spacing Button/input padding, card content, form fields, label-to-input 8, 12, 16, 20, 24, 32px
Layout spacing Sections, containers, page-level spacing, major content blocks 24, 32, 40, 48, 64, 80, 96, 128px

AI Rule

Generated interfaces must use a value from this page's Micro / Component / Layout scale for every margin, padding and gap - never an arbitrary pixel value, and never a value interpolated between two scale steps to arrive at a novel spacing.
