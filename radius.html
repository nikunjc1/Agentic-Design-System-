Radius

The corner-radius language every control, container and surface in this system borrows from - a visual signal of hierarchy, not just a rounded corner.

What are you building?

Pick the product type closest to yours and the recommended radius philosophy below updates to match - you can still choose a different one manually afterward.

Recommended

Radius philosophy

The corner-rounding character every control, card and surface in this system follows. Balanced is the global default unless your product type above recommends otherwise.

Recommended global model

Radius communicates hierarchy - smaller values read as precise and utilitarian, larger values read as container or emphasis.

Radius by component role

Micro components Small badge, tiny indicator, chip, compact control 2, 4px
Interactive components Button, input, select, checkbox, search field, dropdown - default 8px 4, 6, 8px
Content components Card, info panel, notification, form container - default 12px 8, 12, 16px
Large surfaces Modal, dialog, drawer, bottom sheet, dashboard container - default 16px 12, 16, 24px
Floating / overlay Popover, tooltip, dropdown menu, context menu - default 8px 6, 8, 12px

Component defaults

Button Compact enterprise 4px · expressive consumer 12px · pill uses Full 8px
Input / Select / Textarea Share one control radius across every form field 8px
Card Compact enterprise 8px · soft consumer 16px · expressive 20-24px 12px
Modal / Dialog Compact enterprise 12px · large/expressive 20-24px 16px
Badge Chip uses 8px; pill status uses Full - not every badge should be a pill 4px
Tooltip / Popover / Dropdown Keep floating surfaces tighter than content containers 8px
Table Round the container only - individual cells stay 0px to avoid fragmentation 8px
Avatar / Icon Button / Toggle Circular only when width equals height Full

AI Rule

Generated interfaces must take a component's corner radius from this page's Component Defaults mapping - never invent a radius value, and never round a component that isn't listed here without first adding it to the mapping.
