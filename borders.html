Border states

Each state below can independently vary width, color, opacity and style - none of them should ever be the only signal for what's happening.

Default The resting state every bordered component starts from 1px · 70% #
Hover Same width, a touch stronger - or inherit Default unchanged 1px · 100% #
Focus Never subtle - pair with a visible ring, not color alone 2px · 100% #
Active Pressed/engaged state, usually the brand color 2px · 100% #
Selected Reserve the space at Default width to avoid layout shift 2px · 100% #
Disabled Muted, never fully invisible - the boundary still matters 1px · 60% #
Error Pair with an icon and message - border is never the only signal 1px · 100% #
Warning Pair with an icon - don't rely on color alone 1px · 100% #
Success Pair with an icon - don't rely on green alone 1px · 100% #
Info Neutral-to-brand informational emphasis 1px · 100% #
